**覆盖范围**

**拆解结论示例**
- 花园系统用「位置稀缺」（11 种可种植物 vs 8 个花圃位）做取舍，而不是加产出上限
- 宝石作为唯一通货，同时承担硬通货与养成入口，把两个本会打架的循环焊成一个
- 伤害曲线采用「顺位配平」而非「数值配平」——玩家感知整齐，代价是插入新武器时难以不破坏顺位

## 02 · 《宿舍求生》玩法设计方案

**性质**：完整原创策划方案 ｜ 3D 百人竞技生存游戏 · v3.0

> 一百名学生被困在一栋会自己收拾干净的宿舍楼里——白天拆家、找线索；晚上守门、挨怪潮。
> 你可以杀光所有人自己走，也可以翻开那本记着所有死者名字的点名册，把这一晚走完。

| 指标 | 数量 |
| --- | --- |
| 主方案 | **632 行**（约 2.2 万字） |
| 数值表 | **7 册 / 55 张 / 1,142 行数据** |
| 武器 | 69 件，其中 53 件战斗向 |
| TTK 平衡 | 全部锁死 **2.00–4.00 秒**，跨档总极差 **2.00 倍**，严格支配关系 **0 对** |
| 单局规模 | PC 100 人 / 60 队 / 6 层 150 间 / 3 昼夜 24 分钟 |

**四个核心设计**

1. **昼夜是两套玩法** —— 白天采集效率 100% / 夜晚 60%，白天击杀只掉 50% 材料、夜晚全掉。
   *用经济代价而非硬规则，让「白天各干各的、晚上才真打」自然形成。规则禁止的东西没人讨论，经济上不划算的东西才会形成默契。*
2. **双通关线** —— 清场（零和）与解谜归寝（正和）互斥不可逆。三处合闸点分设 1F / 6F / B1，让合作的三支队在物理上互相打不到。
3. **反数值膨胀** —— 最高档 T5 只放 4 件，且以机制独特性取胜；BOSS 不掉落任何数值奖励，只产出「通关资格」。
4. **用资源结构逼出合作** —— 单队对 Lv3 材料覆盖率仅 36%–58%，3 队合并才全部达标（108%–174%）。

**工程化程度**：每个工作簿首页都有表目录、7 册可互相导航；另附 16 个调参旋钮与风险开关；全部数值由脚本生成，可回归校验。
