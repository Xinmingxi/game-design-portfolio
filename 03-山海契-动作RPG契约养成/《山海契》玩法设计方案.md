# 《山海契》玩法设计方案

**SHAN · HAI · QI** · Baseline v1.0

> 你在山海之间行走，收下妖留下的蛋，或与幼崽立契；妖能替你打，也能反咬你——契约不是收服，是长期共处。

**文档性质**：原创方案，游戏策划求职作品集主体件；同时作为后续网页可玩切片的施工图。
**形态**：PC 单机（Steam 优先）· 第三人称低模 3D · 键鼠 + 手柄 · 无联网、无内购。
**规模**：3 个区域 / 30 个探索节点 / 14 种妖 / 18 件近战兵器 / 4 类射器 / 16 种消耗品。
**主线时长目标**：12 小时（口径见 §10.3）；全收集 22–25 小时。
**编号约定**：本文所有数值都是「可复算的量级」，不冒充实测。凡属估算的，行内标 **[估算]**；凡引用文献或器物但我无法当面核到原文的，标 **[待核]**；其余为可直接落地的设计定值。

## 1. 项目定位

### 1.1 一句话卖点

**这不是一个「抓宠」游戏，是一个「共处」游戏。** 你比妖强，所以你签得下它；也正因为你只是「比它强一点」，所以它会记仇、会试探、会在你最虚的时候反咬。玩家要管理的不是妖的等级，而是**一段随时可能翻面的关系**。

支撑这句话的三个机制承诺：

1. **强行签约永远可选，但代价是一次押上性命的赌**——主角战力与妖战力的比值直接换算成反噬概率，且在契约期内每天都要重新兑现一次。
2. **妖不会因为你打赢它就服从**。信赖值只能靠喂食、疗伤、并肩、让它自己做决定来养，且**每天自动衰减**。
3. **兵器和射器都不给上位替代**。18 件近战兵器共用一条「预算线」，任意两件之间不存在严格支配关系（§6.3 给了可执行的自检脚本口径）。

### 1.2 品类与平台定位

| 项 | 定位 | 依据 |
| --- | --- | --- |
| 品类 | 动作角色扮演 + 契约养成（Action RPG / Creature-bonding） | 战斗是实时兵器对拆，不是回合制；养成对象是「关系」而非「等级」 |
| 视角 | 第三人称越肩，可拉远到俯视 45° | 既有近战距离感，又能看清妖在侧翼的站位（信赖预警靠站位读） |
| 平台 | PC（Steam / itch.io），Steam Deck 可玩 | 兵器与射器需要精细输入；不做移动端，避免触及简化近战系统 |
| 引擎 | Godot 4（主推）/ Unity 备选 | 小团队、无授权费；网页切片另用 Three.js 重写核心循环，不共用工程 |
| 单局结构 | 无「一局」，是「一次外出（Excursion）」：15–20 分钟一段 | 与妖的信任建立需要可预期的短周期节奏 |
| 目标人群 | 喜欢《怪物猎人》的资源—装备—再出发，以及《环世界》式关系张力的玩家 | 战斗手感 + 关系管理双卖点 |
| 难度档 | 三档：留客（反噬概率 ×0.6）/ 本事在原（×1.0）/ 强者为尊（×1.4） | 反噬概率是唯一随难度缩放的核心量 |

**明确不做**：开放世界无缝大地图、联机、PVP、抽卡、内购、体素建造、程序生成地形（区域是手工白盒）。

## 2. 世界观与非修仙的五条硬边界

### 2.1 世界的三句话

1. **山海之间有一条「界」**，界内是人的村镇与驿道，界外是《山海经》里写过的山、水、兽。界不是墙，是「路走不通的地方」——所以你不能飞过去，只能找路、找船、找绳。
2. **人比妖弱，是常态；你能签下妖，是因为你比「这一只」强。** 山里活下来的人靠三样东西：手上的兵器、背上的射器、以及一只能替你挡一下的妖。三样都是消耗品。
3. **没有人成仙。** 山里的老人会画符、会布阵、会炼丹，也会老死、会病死、会被自己炼的丹毒死。这套体系里的超自然力量一律**短、local、要付材料钱**（§8.4）。

### 2.2 五条硬边界（禁止清单 + 玩家可感知后果）

这五条是设计评审的一票否决项。左列写禁令，中列写「边界内可以做什么」，右列写**玩家在屏幕上能看见什么**——边界如果不能被玩家感知，就等于没写。

| # | 禁止什么（评审红线） | 边界内可以做什么 | 玩家可感知后果（UI / 反馈层） |
| --- | --- | --- | --- |
| B1 | 禁止飞升、成仙、羽化、渡劫等任何形式的「超脱结局」 | 结局只有两种：**出山**（带妖离开，人妖都还是血肉）与**守山**（留下看界，人会老） | 全流程不存在「突破/境界提升」的过场；结局演出是走路走出画面，没有光柱、没有飞天 |
| B2 | 禁止境界等级与等级数值（练气/筑基/金丹，Lv.1–99，战力数字膨胀） | 主角只有三维：**体魄 / 技艺 / 器**（0–20 点，手工加点，无等级）；妖只有**性情 / 战力指数 / 信赖**，且战力指数不随游戏时长自然增长 | UI 上不出现 Lv. 字样与经验条；妖的成长表现为**新动作、新命令、新的拒绝方式**，而不是数字变大 |
| B3 | 禁止御剑、御风、飞行位移、瞬移类移动能力 | 位移只有：步行、攀爬（体力消耗）、索道与绳索、竹筏 | 地图上所有「看着能飞过去」的断崖都标了绳桩；没有飞行快捷方式，绕路是设计的一部分 |
| B4 | 禁止无代价增益：仙丹、永久属性丹、无限符箓、瞬发万能符 | 一切增益都有**窗口、剂量、材料**三重代价；符箓 6 秒内失效、丹药有耐受与毒性、阵法需 2.5 秒布设且不可移动 | 吃第二枚同种丹药时，屏幕出现「耐受 +1」并让药效数字变灰；连续三枚触发中毒条 |
| B5 | 禁止「收服即忠诚」与「无限随身妖群」 | 出战妖 **1 只**，待命妖 2 只（营地内）；契约可被妖单方面撕毁 | 队伍栏只有 3 格且标「营地」；妖在战斗中会**转头看你**而不是看敌人（§5.4 预警 #3） |

### 2.3 灰区：可以做，但仍被上面五条管着

最容易被误认成「修仙」的五件事，统一按"没有灵力、只有材料"处理：火符烧的是**背在身上的油纸硫朱砂**（6 秒、半径 2.5 m）；阵是**地上的绳旗砂**，会被踩断、会被火烧；止血丹回 35% 血但中毒条 +1；妖的本事来自**体质与本能**（吐毒、振翅、冲撞），不是修为，它也不教你法术；与妖共感只做**情绪读数**（§5.4 预警），不做心灵感应、不做双修。

### 本节验收

> 逐条核对：把 §2.2 五条禁令写成 5 条自动化检查——全工程文本搜索「飞升 / 境界 / Lv. / 御剑 / 无限」五个关键词，命中数必须为 0；且每个存活的玩家可见增益条目，都必须能在 §8 的消耗品表里找到对应的「材料成本 + 剂量上限」两列。

## 3. 核心循环

一次完整循环是**一条 15–20 分钟的外出线**：你从营地（灶台）出发，沿手工白盒的地图节点推进，路上要么撞见一只活着的妖，要么捡到它留下的**蛋**——捡蛋是这条线里唯一「不用赌命」的签订入口，代价是三天孵化期和一只不知道性情的幼崽；撞见成体则要立刻做选择：**收刀、献物、等它靠近**（自愿），还是**趁它没回血、拿绳子套住**（强行）。签下之后，妖进你的队伍，但它不会因为你签下它就服从你——你必须在回营地的路上喂它、给它梳毛或包扎、在下一场遭遇里和它并肩而不是把它当肉盾，信赖值才涨；信赖涨到阈值，它才会在你挨致命一击的时候替你顶一下，也才会在你命令它绕后的时候真的绕后。与此同时，每一场战斗都在消耗你兑现「我比你强」的能力：血量、疲劳、兵器耐久同时在掉，而妖的战力指数不随你掉血而掉——**战力比值 R 在战斗中会自己往下走**，这就是反噬风险的物理来源，它不是随机数，是你打到第 4 分钟时真的变弱了。打赢、带回材料、把妖安顿进营地、用材料修兵器与补符纸，然后推进到下一个节点或下一个区域——循环闭合。

**节奏预算（单次外出，20 分钟版）**

| 阶段 | 时长 | 玩家在做什么 | 系统在给什么压力 |
| --- | --- | --- | --- |
| 出营与赶路 | 3 min | 选路线、看天气、决定带几张符 | 负重上限（30 格）、天气（雨影响符箓） |
| 发现（蛋/巢/遗物） | 3 min | 取舍：这枚蛋值得占一个契约位吗 | 契约位有上限（1 出战 + 2 营地） |
| 遭遇 | 6 min | 兵器距离管理 + 射器起手 + 妖协同 | 兵器耐久、妖的信赖在读条 |
| 签订或放弃 | 2 min | 自愿（献物、等）或强行（套绳、赌 R） | 反噬概率实时显示为一条「危险带」 |
| 培养 | 3 min | 喂、包扎、让它自己走一段 | 信赖每日衰减在倒计时 |
| 回营结算 | 3 min | 修兵器、炒丹、画符、存档 | 材料只够做三件事里的两件 |

### 本节验收

> 循环必须能被「掐表」验证：在切片里从出营按下开始，到回到营地存档为止，用日志打点六个阶段的时间戳；每个阶段的实际耗时与上表偏差不得超过 ±40%，且「签订或放弃」阶段不得为 0（否则说明玩家在一次外出里没有做任何契约决策）。

## 4. 签订系统

### 4.1 两条路径的定位

| 维度 | 自愿立契（Voluntary） | 强行签约（Forced） |
| --- | --- | --- |
| 叙事 | 它走过来，你把吃的放在地上，收刀 | 你把它按住，绳子套上脖子 |
| 前置门槛 | 高（惊扰低、血量高、有对的献物） | 低（只要能打到它虚弱） |
| 初始信赖 | 20–45（按献物匹配度） | 5（并有 7 天「记仇期」每日 −1） |
| 一次性代价 | 献物（消耗品）+ 1 天冷却 | 镇物（铁链/铜铃）+ 立契瞬间 −15 信赖 |
| 长期风险 | 低（但养得慢，妖会自己走开） | 高（R 会随你受伤下降，反噬概率是活的） |
| 适用对象 | 性情温和、可接近的幼崽/成体 | 稀有、强力、不肯靠近的成体（九尾狐、穷奇） |

**两条路都必须长期培养**——这是硬约束：自愿签下的妖初始信赖最高只到 45（未过 60 的「亲近」段），强行签下的妖初始 5。任何路径都拿不到「一签就满信赖」的妖。

### 4.2 自愿立契：判定条件 + 成功率公式

**硬性前置（不满足则选项不出现，不进入概率）**

| 编号 | 条件 | 不满足时的表现 |
| --- | --- | --- |
| G1 | 妖处于「未激战」状态（最近 8 秒内未攻击你） | 立契键灰显，提示「它还在扑」 |
| G2 | 兵器在鞘内，且未点火把 | 提示「刀在手，它不敢过来」 |
| G3 | 妖当前血量 ≥ 60% | 提示「伤成这样，它只会拼命」 |
| G4 | 该妖种在本周目未被你强行签过 | 提示「山里传开了」（同种自愿概率 ×0.5） |
| G5 | 惊扰度 ≤ 40（见 §4.5 惊扰来源） | 提示条变红：「它在退」 |

**成功率公式（加权线性，权重合计 +0.95 / −0.25）**

P_vol = clamp( 0.10 + 0.30·M_offer + 0.20·Q_calm + 0.12·Q_gear + 0.13·Q_bond + 0.10·Q_tool − 0.25·D_breed , 0.03 , 0.90 )

| 因子 | 含义 | 取值 | 权重 |
| --- | --- | --- | --- |
| 基础项 | 人妖之间的天然不信任 | 常数 | +0.10 |
| M_offer | 献物匹配度：献对的食物/物件 = 1，气味相近的 = 0.5，无关 = 0 | 0 / 0.5 / 1 | +0.30 |
| Q_calm | 1 − 惊扰度/100 | 0–1 | +0.20 |
| Q_gear | 收刀且未点火 = 1；收刀但点火 = 0.5；持械 = 0（且 G2 已拦） | 0–1 | +0.12 |
| Q_bond | 初见 = 0；第二次见面 +0.4；第三次起 +0.7；有过献物史 +1 | 0–1 | +0.13 |
| Q_tool | 用铜铃/兽笛/蒙面等器物辅助 | 0 / 1 | +0.10 |
| D_breed | 妖的野性系数（图鉴给定，0–1） | 0–1 | −0.25 |

**算例（可复算）**：狌狌 D_breed = 0.30，第三次见面（Q_bond 0.7），带野果（M_offer 1），惊扰 20（Q_calm 0.8），收刀未点火（1.0），无铃（0）：
P = 0.10 + 0.30 + 0.16 + 0.12 + 0.091 + 0 − 0.075 = **0.696** ≈ 70%。

失败代价：不受伤，妖离开该节点，**该节点当日不可再尝试**（+1 天冷却）；惊扰度 +15，但 Q_bond 不清零（它记得你来过）。

### 4.3 强行签约：成功率公式

P_force = clamp( 0.15 + 0.45·g(R) + 0.15·W_weak + 0.10·X_tool − 0.25·D_breed − 0.15·H_hurt , 0.05 , 0.95 )

其中 g(R) = clamp((R − 1) / 0.8, 0, 1)，W_weak = 妖血量 < 40% 时为 1，X_tool = 有镇物（铁链、铜铃、缚妖索）时为 1，H_hurt = 玩家血量 < 60% 时为 1。

### 4.4 「主角强于妖」怎么变成数值

这是本作最核心的张力，所以它必须是一个**每次战斗都会被重算的实时量**，而不是一张静态表。

**战力指数 CPT（Combat Power Tally）**

主角：CPT_hero = (体魄 × 0.40 + 技艺 × 0.35 + 器 × 0.25) × S
妖： CPT_yao  = 图鉴基础战力 B × (当前血量% ) × 状态系数（怒 1.15 / 常 1.0 / 疲 0.85）

- 体魄 / 技艺 / 器 各 0–20 点，手工加点，无等级（符合 §2.2 B2）。「器」= 当前兵器与射器的综合评分（兵器表给 1–20 的器值）。
- S = HP% × (1 − 疲劳×0.3) × (1 − 伤病×0.2)，取值约 0.3–1.0。**这就是「你打到第 4 分钟会变弱」的数学表达。**
- R = CPT_hero / CPT_yao。

| R 区间 | 判定 | 强行成功率 P_force | 立契瞬间反噬概率（**UI 参考值，判定以 §4.6 T1 为准**） | 设计意图 |
| --- | --- | --- | --- | --- |
| R ≥ 1.60 | 稳（压制） | 0.68–0.85 | **0%（立契失败只是妖逃走，不反噬）** | 你能签下大多数中低阶妖，这是正反馈 |
| 1.25 ≤ R < 1.60 | 可控 | 0.45–0.68 | **0%（同上）** | 主流体验区，需要镇物与补状态 |
| 1.00 ≤ R < 1.25 | 危险 | 0.22–0.45 | **40%**（K3 默认 45% 时 R=1.24 处的值；档内自 45% 递减到 40%，R ≥ 1.25 直接跳到 0） | 想签九尾狐就得打到半死并保证自己满血 |
| R < 1.00 | 禁止 | — | **100%（即时反噬）** | 立契键变红，按下去 = 当场被咬 |

> 口径说明：**危险档会反噬（见 §4.6 T1），强档不反噬**——R ≥ 1.25 时立契失败只是妖逃走。第四列的具体数字由 §12 的 K3 旋钮决定（K3 默认 45%：档内自 R=1.00 处的 45% 递减到 R→1.25 处的 40%）；早前版本写的 2% 与 8–18% 均已作废。

**算例（可复算）**：中期主角 体魄 11 / 技艺 13 / 器 15 → 基础 = 4.4 + 4.55 + 3.75 = 12.7；HP 70%、疲劳 0.2、无伤 → S = 0.7 × 0.94 = 0.658 → CPT_hero = 8.36。
狰 B = 9.5，血量 35% → CPT_yao = 3.33，R = 2.51 → 落「稳」区，P_force = 0.15 + 0.45×1（g 已封顶）+ 0.15（虚弱）+ 0.10（有链）− 0.25×0.6（D_breed 0.6）− 0 = **0.70**。
若此时玩家血量只有 45%（H_hurt 1）：CPT_hero 降到 5.37 → R = 1.62（仍勉强在「稳」区），但 g(R) 已不再封顶而是 0.77，H_hurt 又扣 0.15 → P_force = 0.15 + 0.45×0.77 + 0.15 + 0.10 − 0.15 − 0.15 = **0.45**（早前版本误写 0.55，那里漏了"R 同时下降"这一步）。**这就是数值设计要表达的「强一点」而不是「强很多」：血量从 70% 掉到 45%，成功率从 0.70 掉到 0.45——掉血对强行签约是双重惩罚，血掉一半，成功率掉的不是一半。**

## 5. 信赖值系统

信赖值 Trust（0–100）是唯一贯穿全局的关系量。**它不参与战斗伤害加成**——妖打多少伤害由它的战力指数决定，与信赖无关；信赖决定的是**它听不听、跑不跑、救不救**。这个切分很重要：把信赖做成伤害加成，等于把关系变成又一个数值槽；做成行为开关，玩家才会真的去读它的动作。

### 5.1 来源（每一次都能在日志里找到一行）

| 事件 | ΔTrust | 每日上限 | 说明 |
| --- | --- | --- | --- |

| 喂错食物 | +1 | +2 | 它吃了，但没记住 |
| 包扎/梳理（消耗草药 ×1） | +5 | +10 | 需要安静环境，战斗中不可用 |
| 并肩参战且它造成伤害 | +2 | +6 | 「并肩」要求你在 8 m 内 |
| 协同击杀（你的最后一击与它的攻击在同一 1.5 秒内） | +5 | +15 | 唯一的高效来源，鼓励真打配合 |
| 它自主行动后你**没有**打断（放它去嗅、去追、去玩） | +4 | +8 | 「让它自己做决定」 |

### 5.2 衰减

**基础衰减 0.8 / 日**（游戏内 1 日 = 1 次外出 + 1 次营地结算，见 §10.3 时间口径）。衰减在每日营地结算时一次性扣除，不随时间连续掉——玩家要能看到「昨天 62，今天 61.2」这种可读的变化。

修正：雨天在外过夜 ×1.5；妖在营地被其他妖压制（营地妖 > 2 只） ×1.3；有「梳毛日常」习惯（连续 3 日包扎） ×0.5。

## 6. 近战：十八般武艺

### 6.1 体系来源与设计原则

取民间通行口诀「**刀枪剑戟，斧钺钩叉，镋棍槊棒，鞭锏锤抓，拐子流星**」共 18 件。这套口诀是明清以降的通行说法，**具体定型年代与来源文献待核**；本文不假装它是某本书里的定本，只承诺「18 件全部是真实存在的中国冷兵器」。

三条设计铁律：

1. **无上位替代**：任意两件兵器之间不存在「伤害更高、攻速更快、长度更长、耐久更高」四项全优的关系。
2. **每件兵器至少一个「不能打」的场景**——不是弱，是无效（例：槊在室内不可用；抓对远距离目标无效）。
3. **器值 1–20 参与战力指数 CPT**，所以换兵器不只是手感差异，它直接改变 R（§4.4），进而改变反噬概率。**这是近战系统与契约系统唯一的耦合点，也是本作最想被看见的设计。**

### 6.2b 横扫角取值依据（[估算]，按攻击动作给，不许一律 90°）

横扫角不是"手感参数"，它决定一件兵器**能不能在群战里同时威胁两三个目标**，也决定它在支配自检里站在哪一档。分六档：

| 档 | 角度 | 代表兵器 | 取值理由（一句） |
| --- | --- | --- | --- |
| 纯刺 | 20–25° | 槊 20 / 枪 25 | 只有直线送出，手腕不横向打开 |
| 短促集中 | 30–45° | 锤 30 / 斧 35 | 单次下劈砸在同一竖面内，锤只砸不扫 |
| 中幅 | 50–70° | 戟 50 / 钺 55 / 镋 60 / 剑 70 / 叉 70 | 一器多用，但主要杀伤仍单向 |
| 横扫 | 80–100° | 锏 80 / 刀 90 / 鞭 90 / 钩 100 | 靠横向拖带杀伤（刀）或靠拖拽为生（钩） |
| 抡扫 | 110–130° | 棒 110 / 拐 120 / 棍 130 | 抡圆一记盖身前大半；扫就是棍的全部 |
| 全域 | 180° | 流星 180 | 绳锤可绕身打到身后，故必须付自伤代价 |

**为什么不能统一 90°**：那会让"长度 × 扫角"退化成"长度 × 常数"，2.8 m 的槊与 0.65 m 的锤只差长度——凭空造出 7 对支配（§6.3 实测）。

### 6.3 反支配自检（可执行）

**预算式**：K = 伤害 × 攻速 × √长度。取 √长度 是因为「触及长度」对控场的边际收益递减——从 0.9 m 到 1.9 m 是质变（能先手），从 2.4 m 到 2.8 m 只是量的差别。

**四个独立轴（不是三轴）**

| 轴 | 定义 | 为什么必须独立 |
| --- | --- | --- |
| 输出轴 | 伤害 × 攻速（DPS） | — |
| 触及轴 | 长度（m） | 决定"谁先手"，是独立价值 |
| 覆盖轴 | 横扫角（度） | 决定"能不能一次打两个"，也是独立价值 |
| 持续轴 | 耐久（命中次数） | 决定"这一趟能打几场" |

> **必须承认的修正**：早前版本写「控制轴 = 长度 × 横扫角」，两轴相乘是错的——套上原表（统一 90°）报 7 对，按动作给扫角后**反而恶化到 32 对**（同一张表换成现行数值仍有 27 对）：槊的 长度×扫角 = 0.98，竟低于 0.90 m 的刀（1.41）。2.8 m 长槊在"控制"上输给短刀，只能是度量错，不是数据错。**故本版拆成「触及」与「覆盖」两个独立轴。**

**支配判定**：若存在 A、B 两件，A 在四轴上均 ≥ B，且至少一轴上 > B 的 1.15 倍，则 A 支配 B，判为设计缺陷。（1.15 是"宽容带"：相差 15% 以内视为同档，不追究。）

**组合数口径**：18 件剔除「抓」= 17 件，两两组合 C(17,2) = **136 对**（早前版本此处的组合数算错，已作废）。剔除「抓」：它是控制件，K 口径不适用、无横扫动作，另用控制时长 1.5 s / 承载 80 kg 单独校验。

**归零是三步工序，不是一次宣布。** 下面每一步都可以被打断、被复核、被别人重跑。

**第 1 步 · 先按设计意图把表填完，再跑一遍：8 对支配**

| # | 支配者 → 被支配者 | 第 3 步归零时补的那一轴 | 具体动作 |
| --- | --- | --- | --- |
| 1 | 刀 → 斧 | 持续（耐久） | 斧 耐久 230 > 刀 220 |
| 2 | 剑 → 斧 | 持续（耐久） | 斧 耐久 230 > 剑 210 |
| 3 | 钩 → 斧 | 持续（耐久） | 斧 耐久 230 > 钩 210 |
| 4 | 刀 → 钺 | 触及（长度） | 钺 长度 1.05 > 刀 0.90 |
| 5 | 剑 → 钺 | 触及（长度） | 钺 1.05 > 剑 0.95 |
| 6 | 钩 → 钺 | 触及（长度） | 钺 1.05 > 钩 1.00 |
| 7 | 棍 → 叉 | 输出（DPS） | 叉 伤害 34 → DPS 47.6 > 棍 45.6 |
| 8 | 棍 → 棒 | 输出（DPS） | 棒 伤害 38 → DPS 49.4 > 棍 45.6 |

读法：左两列是"谁不该赢却赢了"，右两列是"被支配者本该在哪一轴上赢回来"。**8 对只落在三根轴上（持续 3、触及 3、输出 2），没有一对需要靠扫角去救**——这恰好说明扫角列不是用来凑数的，它只在真正该分开的地方起作用（见本节末"棍 vs 叉"）。

**第 2 步 · 逐对查"它本该在哪一轴赢"，补数——第一轮 5 个、第二轮 1 个，共 6 个**（每处都补在它自己的强项上，不是随便加数）：

| 兵器 | 改前 → 改后 | 为什么这样改 |
| --- | --- | --- |
| 剑 | 耐久 240 → **210** | 它的缺点本就写着"耐久低于刀（刃薄易损）"，而原表 240 > 刀 220——**表与文互相打脸，是原文的错** |
| 斧 | 耐久 200 → **230** | 厚背斧以厚度换耐久；弱项已够（慢 + 僵直），不该再叠"最容易坏" |
| 钺 | 长度 0.85 → **1.05**，扫角 45 → **55** | 大钺本是长柄执器（《牧誓》"左杖黄钺"），给点触及才配得上"破甲最高、其它最差" |
| 叉 | 伤害 30 → **34** | "中距万金油"的原值 DPS 低于齐眉棍，与定位矛盾 |
| 棒 | 伤害 34 → **38**，耐久 280 → **250** | 杆棒靠击倒与耐久吃饭，DPS 不该垫底；耐久让给鞭、锏 |
| 锏（**第二轮**） | 耐久 250 → **265** | 上一行把棒升到 DPS 49.4 后，**冒出一对新支配：棒 → 锏**（棒 49.4/1.30/110°/250 全面压过锏 48.3/1.05/80°/250）。锏本来的身份是"实心铁条、比带刃兵器耐砸"，所以补在持续轴：265 > 棒 250，赢回一轴 |

**第 3 步 · 再跑：0 对**

136 对组合中，**四轴支配对 = 0**；全表 K 区间 **49.5 – 68.2**，极差 **1.38 倍**。**6 处改动**（第一轮 5 个 + 第二轮 1 个）全部落在 §6.2 表内，没有一处改动去碰 K 区间（改后再算 K 仍全在区间内），所以这轮修的是"谁都能赢一点"，不是"把数字往上抬"。

**示范一对（扫角如何拉开差距）——棍 vs 叉**

| 轴 | 棍 | 叉 | 谁赢 |
| --- | --- | --- | --- |
| 输出 DPS | 45.6 | **47.6** | 叉（+4%） |
| 触及长度 | **1.90 m** | 1.70 m | 棍（+12%） |
| 横扫角 | **130°** | 70° | 棍（**+86%**） |
| 耐久 | **300** | 240 | 棍（+25%） |

叉靠 DPS 赢一轴（所以棍不能支配它），棍靠扫角与耐久赢两轴（所以叉也不能支配棍）。**这一对就是"没有上位替代"的最小样本**：玩家在"打得快"和"扫得宽、用得久"之间必须选。

### 6.4 哪些取用现实，哪些做了虚构化

| 层面 | 处理 | 说明 |
| --- | --- | --- |
| 器物形制与名称 | **取用现实** | 18 件全部是真实存在的中国冷兵器，名称沿用通行叫法 |
| 技法与流派 | **取用现实，但不做招式系统** | 不做「XX 十三式」技能树；现实技法只体现在攻速、硬直、格挡减伤这些参数上 |
| 文献出处 | **部分待核** | 表中 11 条标了 [待核]：我能说出「哪本书提到过这类器械」，但无法当场核到具体卷次条目，因此不写卷次 |
| 伤害/攻速/耐久 | **完全虚构** | 现实没有 DMG 数字；这些值是为「无上位替代」反推的平衡值 |
| 克制/被克关系 | **完全虚构** | 现实兵器相克主要取决于训练与阵型，与「妖的类型」无关 |
| 预算式 K = DPS × √L | **虚构模型** | 不是为了还原现实，是为了让「没有上位替代」这件事可以被脚本检查 |

### 本节验收

### 7.1 四种射器

**弹弓的存在理由**：本作要活捉妖来强行签约，但「打到半死」会掉 60% 以上的血，反而让妖进入拼命状态。弹弓是唯一能**只降低惊扰、不造成穿透伤**的远程手段，它与 §4.2 的自愿路径直接咬合。

### 7.2 拉距与蓄力

- 蓄力曲线：0–1.2 s 线性上升，伤害系数 = 0.35 + 0.65 × (t/1.2)。
- **过拉惩罚**：t > 1.25 s 后每 0.25 s，散布 +40%，且 2.0 s 后强制脱手（体力 −15）。理由：真实拉弓无法无限持弓瞄准，这是「手感」而不是「规矩」。
- 拉满（1.0–1.2 s）时进入**稳定窗**，散布 −25%——奖励「拉满再放」，但窗口只有 0.2 s。
- 弩无蓄力：扣扳机即发射，代价是装填长。**这是「节奏换精度」的设计**：弓是持续输出，弩是一次性爆发。

### 7.3 弹道与下坠

抛物线：下坠 = 0.5 × g × t²，t = 距离 / 初速，g = 9.8 m/s²。

| 距离 | 角弓（55 m/s） | 蹶张弩（65 m/s） | 连弩（45 m/s） |
| --- | --- | --- | --- |
| 20 m | 0.65 m | 0.46 m | 0.97 m |
| 40 m | 2.59 m | 1.86 m | 3.87 m |
| 60 m | 5.83 m | 4.18 m | 8.71 m |

**玩法含义**：60 m 上角弓要抬 5.8 m（约两个身位），这不是「加个下坠」的装饰，而是让远程**只在中距划算**。所有射器都带一个 3 点准星，准星间距随距离自动张开——玩家抬多少，屏幕告诉得清清楚楚（可读性优先于硬核）。

**移动目标提前量**：提前量 = 目标速度 × 飞行时间 × 0.3（0.3 是「妖会变向」的折扣系数）。例：狰 6 m/s，25 m 处，角弓（55 m/s）飞行 0.45 s → 提前 0.81 m；若换蹶张弩（65 m/s）飞行 0.385 s → 提前 0.69 m。

### 7.4 与近战的互补关系（判据）

**远程更划算，当且仅当以下四条同时成立：**

1. **距离判据**：D ≥ 12 m。（12 m 是「近战两段位移可及」的临界；短于此，远程来不及出手。）
2. **时间判据**：目标突进时间 T_c = D / 目标速度 ≥ 装填 + 瞄准 + 提前量修正。以蹶张弩为例 = 3.2 + 0.6 + 0.2 = **4.0 s**。狰 6 m/s 在 25 m 处 T_c = 4.17 s → **正好够开一弩再切刀**；在 18 m 处 T_c = 3.0 s → 不够，直接切近战。
3. **效率判据**：期望远程 DPS > 近战可及 DPS × 接近率。接近率 = 速度 / (速度 + 兵器长度 × 2)。例：刀（0.9 m）对 6 m/s 的狰，接近率 = 6/(6+1.8) = 0.77 → 近战实际有效 DPS = 60 × 0.77 = 46.2；蹶张弩 25 m 期望 DPS = 单发 90 / (装填 3.2 + 飞行 25/65 ≈ 0.385) = **25.1**（早前版本误用 0.45 s——那是角弓 55 m/s 的飞行时间，已修正）。**结论：对快目标远程不划算**——这正是我们想要的平衡：远程不是万能起手式。
4. **目标类型判据**：目标属「软甲」或「悬空」时远程 ×1.25（软甲吃箭，悬空难被近战够到）；目标属「硬壳」时远程 ×0.6（箭矢弹开），此时必须靠锤/鞭/锏。

**一句话分工**：**近战决定「你能不能活着」，远程决定「你要花多少药」**——远程把妖的血削到便宜的位置，近战负责收尾，但如果玩家全程远程，弹药消耗会吃掉这次外出的全部净收益（见 §8.5）。

**起手 vs 持续：判据 2 与判据 3 各管什么**

判据 3 否定的是**全程躲在远处输出**，判据 2 肯定的是**在接触前抢一箭**——两者测的不是同一段时间。角弓算例（25 m、狰 6 m/s、满蓄单发 60 点 [估算]）：抽箭 0.5 + 蓄力 1.2 + 飞行 0.45 = **2.15 s 出手并命中**，起手窗口 DPS = 60 / 2.15 = **27.9**，仍低于刀的 46.2，与蹶张弩的 25.1 同向——所以「持续远程」确实不成立。但若直接切刀，25 m 处以 6 m/s 接近要 (25 − 1.5) / 6 ≈ **3.92 s** 才进刀的有效距离，这 3.92 s 里输出为 0；起手一箭用掉其中 2.15 s 换来 60 点（= 两刀），余下 1.77 s 够一次翻滚（0.6 s）加起手刀。**结论：起手是「把够不着的时间换成伤害」，不是「少打一会儿近战」。** 自洽边界：要判据 3 继续成立，角弓满蓄单发须 ≤ 46.2 × 2.15 ≈ **99 点**；60 点留了 65% 余量 [估算]，若原型实测调到 100 点以上，持续远程会压过近战，须回调。

| 全收集 | 22–25 h | 主线 × 1.0 + 重复探索 40% + 图鉴与契约收集 |
| 单次「重新开始」成本 | ≤ 40 s | 见 §11.4 |

**为什么区域越来越短、越来越重**：节点数 10 → 11 → 9，但时长 3.0 → 3.5 → 4.0。第三区域每个节点的决策密度更高（一次遭遇里同时有 2 只妖、妖会叛、消耗品会被吞），靠**密度**而不是**长度**堆强度。

### 本节验收

> 用日志统计「单次外出实际时长」，中位数必须落在 15–20 分钟；若中位数 <12 分钟，说明节点太稀或遭遇太少；若 >24 分钟，说明单节点敌人过多。三种区域各测一次，三次都达标才算通过。

### 11.4 失败与重试设计

| 失败类型 | 触发 | 惩罚 | 重试方式 | 重试成本 |
| --- | --- | --- | --- | --- |
| 主角被击倒 | HP 归零 | 回最近营地；丢 25% 采集物；所有妖 Trust −5 | 从营地再出发 | ≤40 s（含加载） |
| 反噬被咬倒 | §4.6 T1/T3 触发 C1 | 同上 + 该个体妖逃走 | 同上 | ≤40 s |
| 妖脱契 | C2 | 永久失去该个体；契约位空出 | 回该区域另找同种 | 一次外出 |
| 契约位满 | 出战 1 / 营地 2 已满 | 必须放生 1 只（该种信望 −1） | 当场决策 | 无 |
| 时间（入夜） | 单次外出超过 25 分钟 | 夜间妖强度 ×1.3，符箓与烟符雨天失效概率上升 | 继续或撤退 | 撤退不惩罚 |

**设计原则**：**惩罚落在「关系」和「材料」上，绝不落在「时间」上**。不给读档惩罚、不做体力值、不做「失败要重打 20 分钟」。因为本作的核心情绪是「我和它的关系出了裂缝，我要去补」，而不是「我被游戏罚了」。

### 11.5 键位表

**设计前提**：右键是「收刀 ⇄ 持械」这个**状态开关**，不是攻击——因为本作里"刀在鞘里"是一个真实的机制状态（§4.2 G2：持械会让妖不敢靠近），它必须有一个随时可按、且不会误触攻击的键。

| 操作 | 键位 | 可否改 | 说明 |
| --- | --- | --- | --- |
| 移动 / 视角 | W A S D / 鼠标 | 可改 | 手柄为左右摇杆 |
| **攻击 / 放箭** | **鼠标左键** | 可改 | 持械=攻击；持弓弩=按住蓄力、松开放箭（§7.2） |
| **收刀 ⇄ 持械** | **鼠标右键** | 可改 | **状态开关**：收刀移速 +10%、惊扰不涨；持械可攻击但妖的初始惊扰 +25 |
| 交互 / 投喂 / 立契 | E | 可改 | 长按 0.8 s 才进立契界面（防误触） |
| 翻滚 / 闪避 | **空格** | 可改 | 耗体力；负重 >70% 距离 −20%。**单键、无修饰**，因为这是战斗反射动作 |
| 符箓 | F（**Q = 换符种**） | 可改 | F 用当前符；Q 切换符箓种类 |
| （预留）修饰键 | Shift | 可改 | **当前不绑定任何动作**，只作修饰键预留（正式版若加"疾跑"直接用它，不必改动其它键） |
| 阵法 | G | 可改 | 2.5 s 布设，移动即打断（§8.3） |
| 丹药 | R | 可改 | 1.2 s 服食，受击打断（§8.4） |
| 切换兵器 | 1 / 2 | 可改 | 切片只有刀 / 枪；正式版 1–4 快捷槽 |
| 妖列表 / 图鉴 | Tab（**点按 <0.25 s**） | 可改 | 看 3 个契约位的 Trust 与段位（§5.3）；点按绝不弹出指令轮盘 |
| 妖指令 | Tab（**按住 ≥0.3 s**） | 可改 | 轮盘在按住满 0.3 s 后才出现；松手执行：左右=跟随/绕后，上=攻击锁定目标，下=退回 |
| 暂停 / 设置 | Esc | 不可改 | — |
| 调试面板 | F1 | **不可改，仅开发构建** | 显示 R / CPT / Trust / 惊扰 / 自检结果；正式包不编译 |

**同键多身份的唯一判定标准**：一个键可以因为**手上拿着什么 / 面前是什么**承担不同语义（上下文切换），但**不能因为"按多久"或"加哪个修饰键"而承担两个战斗中同时要抢的语义**。按这条标准清了一遍表：

| 疑似冲突 | 判定 | 处理 |
| --- | --- | --- |
| 左键 = 攻击 / 蓄力放箭 | **不算冲突**：由手上拿什么决定，二者互斥，不会同时想要 | 保留 |
| 右键 = 收刀⇄持械 | 只有一种语义 | 保留 |
| E = 交互 / 投喂 / 立契 | **不算冲突**：由面前是什么决定（上下文） | 保留，立契另加长按 0.8 s 防误触 |
| Shift = 翻滚 + Shift+F 换符 | **算冲突**：翻滚是战斗反射，Shift 当修饰键会被误触 | **已改**：翻滚移到空格，换符种移到 Q，Shift 降为纯修饰键预留 |
| Tab = 点按列表 / 按住指令 | **不算冲突但需阈值**：无修饰键，且轮盘要按住满 0.3 s 才出现，点按不可能误触 | 保留，阈值写死 0.25 s / 0.3 s |

**两条必须保留的设计**：① 右键是**状态而非动作**——它直接改惊扰（+25），"手放在哪"本身就是一次契约决策；② **Tab 松手后的命令延迟**（Trust<40 时 +0.4 s）——把关系数值做成输入延迟，是这套键位里最值钱的一条。

### 本节验收

> 找 5 个没看过本方案的人玩切片，不看任何说明：其中至少 4 人能在 15 分钟内走完「自愿签约 → 战斗协同 → 强行反噬」三条路径，且事后能自己说出「因为我比它弱，所以它咬了我」这句因果——说出这句的人占比 ≥80% 才算通过。

## 12. 风险开关与调参旋钮

★ 为最高优先级三个。安全区间指「超出这个区间，核心承诺就会被破坏」的边界。

| # | 旋钮 | 调什么 | 影响什么 | 安全区间 | 默认 |
| --- | --- | --- | --- | --- | --- |
| **★K1** | **战力比阈值** | R 的 1.25 / 1.60 两条跳档线 | 「主角强于妖」这一核心承诺的全部体感；调高 → 强行签约变得几乎不可能；调低 → 反噬变得廉价 | **1.15–1.35 / 1.45–1.75**；低于 1.15 则「强一点」的张力消失，高于 1.75 则强行路径实际被删 | 1.25 / 1.60 |
| **★K2** | **信赖日衰减** | 0.8/日 | 「长期共处」的强度：衰减越高，玩家越必须每天带妖出门；越高也越容易让人觉得「被逼打卡」 | **0.5–1.2 / 日**；>1.5 会让 8 日养成变成 14 日，节奏崩 | 0.8 |
| **★K3** | **危险带反噬概率** | R∈[1.0,1.25) 档内的反噬百分比：档内自 K3 递减 5 个百分点（K3=45% → R=1.00 处 45%、R→1.25 处 40%）；R ≥ 1.25 恒为 0 | 高风险高回报的刺激度；也是一周目教学「别贪」的主要来源 | **25%–65%**；<25% 则玩家会无脑强签，>65% 则没人敢碰稀有妖 | 45% |
| K4 | 兵器预算 K 区间 | 49.5–68.5 | 「无上位替代」的可检性；区间越窄越平衡，越宽越有个性 | 极差 **≤1.5 倍** | 1.38 倍 |

| K7 | 符箓携带上限 | 9 张（符囊可升 12） | 消耗品压力的主体；上限越高，战斗越像「扔符」 | **6–12**；>12 则近战被边缘化 | 9 |
| K8 | 丹毒阈值 | 连续 3 枚触发中毒 | 药品的节制感 | **2–4 枚**；>4 则药变成回血包 | 3 |
| K9 | 抗命概率（Trust<40） | 15% | 关系差的「可感知惩罚」 | **10%–25%**；>30% 会让玩家觉得妖是废的 | 15% |
| K10 | 单次外出期望时长 | 15–20 min | 整个节奏的地基 | **12–24 min** | 18 min |
| K11 | 蛋孵化时间 | 3 日 | 拿蛋这条路的时间成本 vs 赌命签约 | **2–5 日** | 3 日 |
| K12 | 单节点材料产出 | 2–4 单位 | 经济净结余 | 净结余 **+2～+6 单位/次** | 2–4 |
| K13 | 反噬伤害系数 | CPT_yao × 3.5 | 反噬是否「疼」到被记住 | **2.5–4.5×**；<2× 无法击倒玩家，格式失效 | 3.5× |
